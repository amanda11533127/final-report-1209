## 啟動方式

本專案為純前端靜態網頁（無需安裝額外套件），可使用以下任一種方式開啟：

### 方式一：直接用瀏覽器開啟
雙擊專案資料夾中的 `index.html` 即可在瀏覽器中預覽。

### 方式二：使用本機伺服器啟動（推薦）
在專案資料夾內打開終端機執行：

```bash
python3 -m http.server 8000
```

接著在瀏覽器開啟 `http://localhost:8000`。

## 組員協作流程

1. 接受 GitHub Collaborator 邀請通知。
2. 複製（Clone）專案到本機：
   ```bash
   git clone https://github.com/amanda11533127/final-report-1209.git
   ```
3. 在 Antigravity 開啟 `final-report-1209` 資料夾開始編輯。
4. 修改完成後同步到 GitHub：
   ```bash
   git pull origin main
   git add .
   git commit -m "說明這次修改內容"
   git push origin main
   ```
